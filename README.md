# جسر (Jisr) – برنامج الكمبيوتر

هاتف أندرويد يعمل كجسر بين أجهزة بلوتوث خارجية وبين الكمبيوتر (ويندوز) عبر الواي فاي المحلية.

```
جهاز بلوتوث  <--بلوتوث-->  الهاتف  <--واي فاي-->  Jisr على الكمبيوتر
```

### [⬇ تحميل Jisr-Setup.exe](../../releases/latest/download/Jisr-Setup.exe)

ويندوز 10 أو 11 (64 بت). كل الإصدارات في صفحة [Releases](../../releases). يحتاج أيضاً تطبيق «جسر» على هاتف أندرويد (8 أو أحدث).

## ماذا يفعل

| الميزة | كيف تعمل |
|---|---|
| **صوت** | الكمبيوتر يلتقط كل صوته ويبثه للهاتف، والهاتف يشغله على سماعتك المقترنة به |
| **الهاتف كماوس وكيبورد** | لوحة لمس على شاشة الهاتف + كتابة نصوص بأي لغة تصل للكمبيوتر |
| **كيبورد / ماوس** | جهاز مقترن بالهاتف تصل حركاته وضغطاته للكمبيوتر كأنه متصل به |
| **يد ألعاب** | وضع سطح المكتب (الماوس والكيبورد) أو وضع الألعاب (يد Xbox 360 افتراضية، تحتاج تعريف ViGEmBus) |
| **أجهزة BLE** | بحث واتصال وقراءة وكتابة واشتراك في الإشعارات |
| **أجهزة تسلسلية (SPP)** | مثل HC-05 وأردوينو: تظهر كمنفذ TCP على `127.0.0.1:47900+رقم القناة` |
| **الحافظة** | نسخ ولصق النصوص بين الهاتف والكمبيوتر |
| **نقل الملفات** | في الاتجاهين وبأي حجم (حتى 8 جيجابايت) مع التحقق من سلامة الملف |

## التثبيت والبدء

1. حمّل `Jisr-Setup.exe` وشغّله. إذا ظهرت نافذة SmartScreen الزرقاء اضغط **More info** ثم **Run anyway** (الملف غير موقَّع رقمياً بعد).
2. اترك خيار **جدار الحماية** مفعّلاً حتى يصل الهاتف إلى الكمبيوتر.
3. افتح **Jisr** من قائمة ابدأ: تظهر نافذة فيها رمز **PIN** ورمز **QR**.
4. في تطبيق الهاتف اضغط «مسح رمز QR» ووجّه الكاميرا نحو النافذة. (أو اكتب عنوان الكمبيوتر والـ PIN.)
5. لتشغيله مع ويندوز فعّل **Start with Windows** من داخل البرنامج. إغلاق النافذة يخفيها في شريط المهام، وللخروج استعمل **Quit**.

لإرسال ملفات من الكمبيوتر للهاتف: زر **Send files to phone...** أو القائمة اليمنى في الإكسبلورر (**Send to > Jisr**، فعّلها من النافذة).

## الأمان والخصوصية

- الاتصال بين الهاتف والكمبيوتر **مشفّر** (AES-256-GCM بمفاتيح مؤقتة لكل اتصال عبر ECDH، ومربوط برمز PIN). خمس محاولات PIN خاطئة تحظر العنوان دقيقة.
- البرنامج لا يتصل بالإنترنت ولا يرسل أي بيانات خارج شبكتك المحلية.
- PIN من 6 أرقام قد يُخمَّن إذا سُجّل الاتصال ثم جرى هجوم بجهاز قوي. لحماية أعلى: `Jisr.exe --pin <رمز أطول>`.
- التشفير مكتوب خصيصاً لهذا المشروع ولم يراجعه مختص تشفير. استعمله على شبكة بيتك الموثوقة، لا على شبكة عامة.
- يحاكي البرنامج الماوس والكيبورد ويقرأ الحافظة، لذلك قد تعترض بعض برامج مكافحة الفيروسات عليه خطأً.
- الإعدادات والـ PIN تُحفظ في `%APPDATA%\BTBridge` (الاسم القديم محفوظ عمداً حتى لا يضيع الاقتران).

## حدود معروفة

- ليس محوّل بلوتوث عاماً: أندرويد لا يتيح للتطبيقات الوصول لشريحة البلوتوث نفسها، فيعمل الجسر لكل نوع جهاز على حدة. لبلوتوث كامل في الكمبيوتر استعمل دونغل USB.
- الصوت يمر عبر الواي فاي ثم البلوتوث فله تأخير (200 إلى 400 ملّي ثانية): مناسب للموسيقى والفيديو لا للألعاب. ميكروفون السماعة غير مدعوم.
- الكيبورد لوحة مفاتيح **فعلية** فقط. أحداث الماوس والكيبورد لا تعمل داخل برامج تعمل كمسؤول إلا إذا شغّلت Jisr كمسؤول.
- الحافظة نصوص فقط (حتى 200 ألف حرف). المزامنة التلقائية مطفأة افتراضياً لأنها قد تنقل كلمات مرور.

## للمطورين

```
cd pc
pip install -r requirements.txt     # cryptography إجبارية، والباقي اختياري
python -m btbridge                  # أو run.bat
python tests/test_server.py         # اختبارات (تعمل بدون هاتف)
build_exe.bat                       # ملف Jisr.exe محمول
```

البناء الآلي: `.github/workflows/build-pc.yml` يبني `Jisr.exe` بـ PyInstaller ثم المثبّت بـ Inno Setup (`pc/installer/Jisr.iss`) على خوادم GitHub، ويجرّب تشغيل البرنامج وتثبيته وإزالته قبل أن ينشره. لإصدار نسخة جديدة غيّر الرقم في `pc/VERSION` وأنشئ إصداراً بنفس الرقم، مثل `v1.0.1`.

المنافذ: 47810 (TCP للاتصال وUDP للاكتشاف)، و47812 (واجهة محلية)، و47900 وما بعده (SPP). تفاصيل البروتوكول في `pc/btbridge/secure.py` و`pc/btbridge/files.py`.
